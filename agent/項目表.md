# 項目表

| 路徑 | 用途 |
| --- | --- |
| `src/` | SSH server 核心程式碼 |
| `src/server.js` | SSH connection/session 路由，維護同 connection 的活動 shell 狀態供 SFTP 使用 |
| `src/command-runner.js` | 白名單 exec、逾時強制終止，以及 SSH channel 中斷時的 pipe/timer/child 清理 |
| `src/shell-runner.js` | 互動 shell、真 PTY lifecycle/resize、subscription 清理與 Linux 前景程序 cwd 查詢；啟動目錄可由函式型 shellCwd 依登入使用者解析 |
| `src/sftp-server.js` | SFTP 協議處理；家目錄登入、shell cwd 跟隨、`ls -l` 清單、批次目錄讀取、有界 READ 與全生命週期 handle 清理 |
| `src/sftp-fs.js` | SFTP 虛擬檔案系統：機器根目錄、家目錄推導與建立、擁有者名稱解析、`ls -l` 字串與屬性變更 |
| `src/sftp-extended.js` | SFTP 進階操作：READLINK / SYMLINK / LINK / SETSTAT / FSETSTAT |
| `src/fs-safe.js` | `SSH_SFTP_FOLLOW_SHELL_CWD=false` 時使用的 SFTP 路徑沙箱解析 |
| `src/connection-guard.js` | 連線限額守衛：全域/per-IP 連線數、單連線認證失敗上限、per-connection channel 上限 |
| `src/proot-paths.js` | FreeRoot `proot.yml` 解析與 PRoot guest/host 路徑、bindings 雙向映射 |
| `src/config.js` | 環境變數載入與型別/範圍驗證，包括 SFTP 跟隨模式開關 |
| `scripts/` | 初始化、密碼雜湊、host key 產生工具 |
| `config/` | 使用者與命令白名單設定範本 |
| `keys/` | SSH host key（不提交） |
| `agent/` | 專案任務與維護記錄 |
| `agent/deep_todos.md` | 完整歷史任務清單 |
| `agent/memory.md` | 讀寫/決策/驗證操作記錄 |
| `agent/question.md` | 上一輪 SFTP 需求的 TDD 驗收標準 |
| `agent/cve-audit-2026-11-24.md` | CVE 遺漏盤查報告：Node 20 EOL、ssh2 CVE-2025-70034、base image OS layer、程式碼層與供應鏈缺口 |

### start.js 相容性修復新增的檔案（2026-11-24）

| 路徑 | 用途 | 依賴 |
| --- | --- | --- |
| `src/host-key.js` | `ensureHostKey` / `generateFallbackHostKey`：ssh-keygen 優先，失敗時產生 ssh2 可解析的 EC P-256（`ecdsa-sha2-nistp256`）金鑰 | node:fs/path/child_process/crypto |
| `src/dev-credentials.js` | `resolveDefaultUsername` / `resolveDefaultPassword`：開發用預設帳密與密碼政策（8 字元下限、72 byte 上限） | `src/auth.js` |
| `test/start-script.test.js` | fallback 金鑰型別、密碼政策、scripts 去重、start.js 無 VM 殘留 | `src/host-key.js`、`src/dev-credentials.js`、`src/auth.js`、ssh2 |
| `test/config-bootstrap.test.js` | `loadConfig()` 不得對機器根 mkdir，但仍建立顯式 `SSH_SFTP_ROOT` | `src/config.js` |

`start.js` 與 `scripts/generate-host-key.js`、`scripts/setup-dev.js` 現在都委派上述兩個共用模組，不再各自內嵌 RSA fallback 與密碼檢查。
