# 項目表

| 路徑 | 用途 |
| --- | --- |
| `src/` | SSH server 核心程式碼 |
| `src/server.js` | SSH connection/session 路由，維護同 connection 的活動 shell 狀態供 SFTP 使用 |
| `src/shell-runner.js` | 互動 shell、真 PTY lifecycle/resize 與 Linux 前景程序 cwd 查詢 |
| `src/sftp-server.js` | SFTP 協議處理；預設跟隨同 connection shell cwd，可切回根目錄沙箱 |
| `src/fs-safe.js` | `SSH_SFTP_FOLLOW_SHELL_CWD=false` 時使用的 SFTP 路徑沙箱解析 |
| `src/proot-paths.js` | FreeRoot `proot.yml` 解析與 PRoot guest/host 路徑、bindings 雙向映射 |
| `src/config.js` | 環境變數載入與型別/範圍驗證，包括 SFTP 跟隨模式開關 |
| `src/vm-config.js` | VM `.env` 設定、空白 fallback 與資源/路徑輸入驗證 |
| `src/vm-runtime.js` | 系統 QEMU 偵測與 Debian-compatible APT rootless 私有 runtime 下載、原子啟用 |
| `src/vm-image.js` | Debian qcow2 下載、SHA-512 驗證、可用空間檢查與安全擴容 |
| `src/vm-metadata.js` | localhost NoCloud metadata，初始化 guest SSH 帳號、OpenSSH 密碼 policy、root filesystem grow 與 final-stage completion callback |
| `src/vm-cpu-limit.js` | cgroup v2 小數 CPU quota；不可寫時記錄整數 vCPU fallback |
| `src/vm-manager.js` | QEMU TCG 啟停、2223 port forwarding、metadata/completion/SSH readiness 與資源 lifecycle |
| `src/qmp-client.js` | QMP capabilities negotiation 與 guest ACPI powerdown |
| `scripts/` | 初始化、密碼雜湊、host key 產生工具 |
| `config/` | 使用者與命令白名單設定範本 |
| `s12ryt/` | 預設 shell 工作目錄；SFTP 無活動 shell 時也從此處開始（不提交） |
| `keys/` | SSH host key（不提交） |
| `vm/` | 持久化 qcow2 VM 磁碟（不提交） |
| `agent/` | 專案任務與維護記錄 |
